# StudyCards — флеш-карточки и тесты

Сайт для подготовки к экзаменам, который можно установить на телефон как приложение.

- **Общие материалы** (сейчас «Letecké právo», 3 блока по 25 вопросов) лежат на сайте. Автор редактирует их с любого устройства, и обновления получают все.
- **Личные карточки** каждый пользователь создаёт сам. Они хранятся только в его браузере.

Сервер и платные сервисы не нужны: сайт бесплатно размещается на GitHub Pages.

---

## 1. Публикация сайта (один раз, ~15 минут)

1. Зарегистрируйтесь на https://github.com.
2. Нажмите **New repository**:
   - название `studycards`;
   - тип **Public** (для бесплатного GitHub Pages репозиторий должен быть публичным);
   - нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**.
4. Перетащите в окно **всё содержимое** папки `studycards`: файлы `index.html`, `sw.js`, `manifest.webmanifest`, `.nojekyll` и папки `css`, `js`, `data`, `icons`. Нажмите **Commit changes**.
   - Файл `.nojekyll` скрыт в Windows: включите «Показывать скрытые элементы» в Проводнике. Без него сайт тоже работает.
5. Откройте **Settings → Pages**:
   - в **Source** выберите **Deploy from a branch**;
   - ветка `main`, папка `/ (root)`;
   - нажмите **Save**.
6. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/studycards/`. Этот адрес и отправьте однокурсникам.

## 2. Как редактировать общие материалы с любого устройства

### Один раз создайте токен доступа

1. На GitHub откройте **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Заполните:
   - **Token name:** `studycards`;
   - **Expiration:** до конца семестра или года;
   - **Repository access:** *Only select repositories* → `studycards`;
   - **Permissions → Repository permissions → Contents:** *Read and write*.
3. Нажмите **Generate token** и скопируйте его. GitHub покажет токен только один раз.

### Работа на каждом новом устройстве

1. Откройте свой сайт и перейдите в «Копия» → внизу ссылка **«Для автора»**.
2. Нажмите **«Включить режим автора»**.
3. Укажите логин GitHub, репозиторий `studycards` и токен. Нажмите **«Сохранить и проверить»**.
4. Редактируйте общие предметы, группы и карточки как обычно. Жёлтая полоса вверху напомнит о неопубликованных изменениях.
5. Нажмите **«Опубликовать изменения»**. Через 1–2 минуты обновление появится на сайте у всех. Однокурсники получат его при следующем открытии сайта.

**Важно:**
- **Токен — это пароль.** Не отправляйте его никому. На чужом компьютере после работы нажмите «Удалить токен с устройства».
- **Если правили с двух устройств,** приложение заметит, что на сайте уже другая версия. Оно предложит загрузить её или перезаписать своей.
- **Если выключить режим автора** с неопубликованными правками, они отменятся.
- **Студенты не могут менять общие материалы.** Публиковать можно только с токеном.

## 3. Для пользователей (однокурсников)

- Откройте ссылку на сайт.
- Чтобы установить на телефон:
  - **Android / Chrome:** меню ⋮ → «Установить приложение»;
  - **iPhone / Safari:** «Поделиться» → «На экран Домой».
- После первого открытия приложение работает без интернета.
- Свои предметы и карточки можно добавлять. Они хранятся только на вашем устройстве; сохраняйте их через «Копия» → «Скачать резервную копию».

## 4. Обновление кода приложения

Если меняете файлы приложения (не карточки), загрузите их в репозиторий заново. Затем увеличьте номер `VERSION` в `sw.js` (например, `v2` → `v3`): тогда у всех обновится сохранённая офлайн-версия.

## Архитектура

Чистые HTML, CSS и JavaScript без сборки и зависимостей. Модули регистрируются в общем объекте `App`.

```
studycards/
├── index.html, manifest.webmanifest, sw.js   оболочка, установка как приложение, офлайн-режим
├── data/shared.json      общий набор (его перезаписывает кнопка «Опубликовать»)
├── css/styles.css
├── icons/                значки приложения
└── js/
    ├── utils.js          id, перемешивание, склонение
    ├── db.js             IndexedDB (subjects, groups, cards)
    ├── editor.js         режим автора, состояние общего набора, настройки GitHub
    ├── repo.js           операции с данными, проверки, права на общие записи
    ├── backup.js         личная резервная копия и формат общего набора
    ├── github.js         чтение/запись файла через GitHub API
    ├── sync.js           загрузка общего набора с сайта и публикация
    ├── ui.js, router.js, app.js
    └── views/            экраны: предметы, предмет, группа, карточки, тест, копия, для автора
```

**Общие и личные записи.** Записи из общего набора помечены `shared: true` и при каждом открытии сайта заменяются версией из `data/shared.json`. Изменить их можно только в режиме автора (проверка в `repo.js`). Личные записи синхронизация не трогает. Резервная копия содержит только личные данные.

**Формат `data/shared.json`:** `{ format: "studycards-shared", version: 1, publishedAt, subjects, groups, cards }`. Структура записей такая же, как в резервной копии.

**В перспективе — магазинное приложение.** Этот же код можно упаковать в приложение для Google Play / App Store, например с помощью Capacitor, не переписывая логику.
