# StudyCards — флеш-карточки и тесты

Сайт для подготовки к экзаменам, который можно установить на телефон как приложение.

- **Общие материалы** (сейчас «Letecké právo», 3 блока по 25 вопросов) лежат на сайте. Автор редактирует их с любого устройства, и обновления получают все.
- **Личные карточки** каждый пользователь создаёт сам. Они хранятся только в его браузере.

Сервер и платные сервисы не нужны: сайт бесплатно размещается на GitHub Pages.

---

## 1. Публикация сайта (один раз, ~15 минут)

1. Зарегистрируйтесь на https://github.com.
2. Нажмите **New repository**:
   - название `studycards`;
   - тип **Public** (для бесплатного GitHub Pages репозиторий должен быть публичным);
   - нажмите **Create repository**.
3. На странице репозитория нажмите **Add file → Upload files**.
4. Нажмите **choose your files**, выделите **все файлы** из распакованного архива (Ctrl+A) и нажмите **Commit changes**. Всего 28 файлов, подпапок нет.
   - Файл `.nojekyll` скрыт в Windows. Без него сайт тоже работает.
5. Откройте **Settings → Pages**:
   - в **Source** выберите **Deploy from a branch**;
   - ветка `main`, папка `/ (root)`;
   - нажмите **Save**.
6. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/studycards/`. Этот адрес и отправьте однокурсникам.

## 2. Как редактировать общие материалы с любого устройства

### Один раз создайте токен доступа

1. На GitHub откройте **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Заполните:
   - **Token name:** `studycards`;
   - **Expiration:** до конца семестра или года;
   - **Repository access:** *Only select repositories* → `studycards`;
   - **Permissions → Repository permissions → Contents:** *Read and write*.
3. Нажмите **Generate token** и скопируйте его. GitHub покажет токен только один раз.

### Работа на каждом новом устройстве

1. Откройте страницу автора по прямому адресу: `https://ВАШ-ЛОГИН.github.io/studycards/#/author`. Ссылки на неё на сайте нет — сохраните адрес в закладках.
2. Укажите логин GitHub, репозиторий `studycards` и токен. Нажмите **«Войти как автор»**. Режим автора включится только если токен действительно даёт право записи в репозиторий.
3. Редактируйте общие предметы, группы и карточки как обычно. Жёлтая полоса вверху напомнит о неопубликованных изменениях.
4. Нажмите **«Опубликовать изменения»**. Через 1–2 минуты обновление появится на сайте у всех. Однокурсники получат его при следующем открытии сайта.

**Важно:**
- **Токен — это пароль.** Не отправляйте его никому. На чужом компьютере после работы нажмите «Удалить токен с устройства».
- **Если правили с двух устройств,** приложение заметит, что на сайте уже другая версия. Оно предложит загрузить её или перезаписать своей.
- **Если выйти из режима автора** с неопубликованными правками, они отменятся.
- **Студенты не могут менять общие материалы.** Без токена режим автора не включается, а публиковать без токена невозможно.

## 3. Для пользователей (однокурсников)

- Откройте ссылку на сайт.
- Чтобы установить на телефон:
  - **Android / Chrome:** меню ⋮ → «Установить приложение»;
  - **iPhone / Safari:** «Поделиться» → «На экран Домой».
- После первого открытия приложение работает без интернета.
- Свои предметы и карточки можно добавлять. Они хранятся только на вашем устройстве; сохраняйте их через «Копия» → «Скачать резервную копию».

## 4. Статистика посещений (видна только вам)

Используется GoatCounter: бесплатно для некоммерческих сайтов, без cookies, без рекламы. Статистика обезличенная. Вы видите:
- число посещений по дням;
- какие разделы, группы и тесты открывали;
- страны;
- тип устройства и браузер;
- откуда пришли.

Имён и личных данных нет.

1. Зарегистрируйтесь на https://www.goatcounter.com (Sign up):
   - придумайте код, например `studycards-lp`;
   - укажите e-mail и пароль.
2. На GitHub откройте файл `analytics.js` → значок карандаша (Edit). Замените строку `const CODE = "";` на `const CODE = "studycards-lp";` (свой код). Нажмите **Commit changes**.
3. На странице автора (`…/#/author`, в режиме автора) нажмите **«Не учитывать мои посещения с этого устройства»** — на каждом своём устройстве. Тогда ваши заходы не попадут в статистику.
4. Статистику смотрите по адресу `https://ВАШ-КОД.goatcounter.com` после входа. Не включайте в настройках GoatCounter публичный доступ к статистике: тогда её видите только вы.

Блокировщики рекламы иногда мешают подсчёту, поэтому реальных посещений может быть немного больше.

## 5. Обновление кода приложения

Если меняете файлы приложения (не карточки), загрузите их в репозиторий заново. Затем увеличьте номер `VERSION` в `sw.js` (например, `v2` → `v3`): тогда у всех обновится сохранённая офлайн-версия.

## Архитектура

Чистые HTML, CSS и JavaScript без сборки и зависимостей. Модули регистрируются в общем объекте `App`.

```
Все файлы лежат в одной папке (без подпапок), чтобы их было просто загрузить на GitHub.

index.html, manifest.webmanifest, sw.js   оболочка, установка как приложение, офлайн-режим
shared.json        общий набор (его перезаписывает кнопка «Опубликовать»)
styles.css         стили
icon-*.png         значки приложения
utils.js           id, перемешивание, склонение
db.js              IndexedDB (subjects, groups, cards)
editor.js          режим автора, состояние общего набора, настройки GitHub
repo.js            операции с данными, проверки, права на общие записи
backup.js          личная резервная копия и формат общего набора
github.js          чтение/запись файла через GitHub API
sync.js            загрузка общего набора с сайта и публикация
study.js           набор карточек для обучения: одна группа или весь предмет
analytics.js       обезличенная статистика посещений (GoatCounter), по умолчанию выключена
ui.js, router.js, app.js
view-*.js          экраны: предметы, предмет, группа, карточки, тест, копия, для автора
```

**Общие и личные записи.** Записи из общего набора помечены `shared: true` и при каждом открытии сайта заменяются версией из `shared.json`. Изменить их можно только в режиме автора (проверка в `repo.js`). Личные записи синхронизация не трогает. Резервная копия содержит только личные данные.

**Формат `shared.json`:** `{ format: "studycards-shared", version: 1, publishedAt, subjects, groups, cards }`. Структура записей такая же, как в резервной копии.

**В перспективе — магазинное приложение.** Этот же код можно упаковать в приложение для Google Play / App Store, например с помощью Capacitor, не переписывая логику.
